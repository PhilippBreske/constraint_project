# Towers Puzzle Solver using SMT (Haskell)

This project implements a solver for the **Towers puzzle** using **SMT
(Satisfiability Modulo Theories)**. The solver is written in **Haskell**
and models the puzzle constraints as SMT formulas which are solved using
the **Z3 theorem prover**.

The project was developed as part of the course *Formale Methoden und
Werkzeuge* at **HTWK Leipzig**.

------------------------------------------------------------------------

# Overview

The **Towers puzzle** is a logic puzzle played on an `n × n` grid
(`3 ≤ n ≤ 9`). Each cell contains a tower with a height between `1` and
`n`.

The goal is to fill the grid while satisfying the following constraints:

## Row constraints

Each tower height appears **exactly once in every row**.

## Column constraints

Each tower height appears **exactly once in every column**.

## Visibility constraints

Numbers around the border of the grid indicate **how many towers are
visible from that direction**.

A tower is visible if **no taller tower appears before it** when viewed
from that side.

## Prefilled cells

Some puzzles contain cells that are **already fixed** and must remain
unchanged.

------------------------------------------------------------------------

# Approach

The puzzle is modeled as an **SMT problem**.

The solver encodes the constraints into SMT formulas and uses an SMT
solver to find a satisfying assignment.

Technologies used:

-   Haskell
-   SMT-LIB standard
-   Z3 solver
-   hasmtlib (Haskell SMT interface)

The project uses **hasmtlib**, an embedded domain-specific language
(eDSL) for constructing SMT formulas and interacting with external
solvers.

------------------------------------------------------------------------

# Project Structure

The program consists of two main components.

## Parser

The parser extracts puzzle information from a **Towers puzzle URL**
generated by Simon Tatham's puzzle collection.

Example representation:

    data Puzzle = Puzzle
      { size :: Int
      , top :: [Int]
      , bottom :: [Int]
      , left :: [Int]
      , right :: [Int]
      , prefilled :: [((Int, Int), Int)]
      }

This structure stores:

-   grid size
-   visibility constraints from all four directions
-   optional prefilled cells

## SMT Encoding

The solver constructs SMT constraints for:

-   row uniqueness
-   column uniqueness
-   visibility conditions
-   prefilled cells

Visibility is computed using a fold that tracks:

-   the current maximum tower height
-   the number of visible towers

Example idea:

    visibleCount x = snd $ foldl f (0, 0) x

# Requirements

You need the following tools installed:

-   **GHC** (Glasgow Haskell Compiler)
-   **Cabal**
-   **Z3 SMT solver**

Install Z3 (Linux):

    sudo apt install z3

Or follow the instructions from the official repository:
https://github.com/Z3Prover/z3

------------------------------------------------------------------------

# Installation

Clone the repository:

    git clone <your-repository-url>
    cd constraint_project

Build and start the interactive environment:

    cabal repl solve

------------------------------------------------------------------------

# Usage

The solver expects a **Towers puzzle URL**.

1.  Open the Towers puzzle generator:
    https://www.chiark.greenend.org.uk/\~sgtatham/puzzles/js/towers.html

2.  Generate a puzzle

3.  Click **"by game ID"** and copy the URL

4.  Run the solver inside the REPL:

    main1 "PUZZLE_URL"

The program will:

-   parse the puzzle
-   generate the SMT formula
-   call the solver
-   print the resulting solution
